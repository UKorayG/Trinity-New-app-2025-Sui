TRINITY

Yaratıcı Hikaye Oluşturma Platformu

Başla

Proje Özeti

Trinity, kullanıcıların rastgele üretilen kelimeleri kullanarak yaratıcı hikayeler oluşturabileceği interaktif bir web uygulamasıdır.

🎯 Amaç

Kullanıcıların yaratıcılıklarını geliştirmelerine ve eğlenceli vakit geçirmelerine olanak sağlamak

🎯 Hedef Kitle

Hikaye yazmayı seven, yaratıcılığını geliştirmek isteyen herkes

⚙️ Backend

Proje Yapısı

Trinity/
├── app.js         # Ana uygulama dosyası
├── server.js      # Sunucu yapılandırması
├── index.html     # Ana sayfa
├── style.css      # Stil dosyası
├── package.json   # Bağımlılıklar
└── .env          # Ortam değişkenleri

Uygulama, modern bir mimari yapıyla geliştirilmiştir ve kolayca genişletilebilir.

Kurulum ve Çalıştırma

# Gerekli bağımlılıkları yükleyin
npm install

# Ortam değişkenlerini ayarlayın
echo "PORT=3000" > .env
echo "OPENAI_API_KEY=your_api_key_here" >> .env

# Uygulamayı başlatın
node app.js

Uygulama http://localhost:3000 adresinde başlatılacaktır.

Kullanım Senaryoları

1️⃣ Başlangıç

Kullanıcı uygulamayı başlatır ve "Başla" butonuna tıklar.

2️⃣ Kelime Seçimi

Sistem rastgele 3 kelime üretir ve kullanıcıya gösterir.

3️⃣ Hikaye Yazımı

Kullanıcı verilen süre içinde bu kelimeleri kullanarak bir hikaye yazar.

4️⃣ Paylaşım

Oluşturulan hikaye kaydedilir ve istenirse paylaşılabilir.
