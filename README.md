# Trinity Uygulaması

Bu proje, modern web teknolojileri kullanılarak geliştirilmiş bir web uygulamasıdır. Uygulama, kullanıcı dostu bir arayüz sunar ve çeşitli özellikler içerir.

## 🚀 Özellikler

- Modern ve duyarlı kullanıcı arayüzü
- Gerçek zamanlı etkileşim
- OpenAI entegrasyonu
- Express.js tabanlı sunucu yapısı
- Çevre değişkenleri desteği

## 🛠️ Kurulum

1. Projeyi klonlayın:
   ```bash
   git clone https://github.com/UKorayG/Trinity-New-app-2025-Sui.git
   cd Trinity-New-app-2025-Sui
   ```

2. Gerekli bağımlılıkları yükleyin:
   ```bash
   npm install
   ```

3. `.env` dosyası oluşturun ve gerekli ortam değişkenlerini ekleyin:
   ```
   # .env örneği
   PORT=3000
   OPENAI_API_KEY=your_openai_api_key_here
   ```

4. Uygulamayı başlatın:
   ```bash
   node app.js
   ```

5. Tarayıcınızda `http://localhost:3000` adresine gidin.

## 🖥️ Teknolojiler

- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Node.js, Express.js
- **Veritabanı**: (Eğer kullanılıyorsa buraya yazılacak)
- **Diğer**: OpenAI API, CORS
